# Filingo-Blog

Der Blog-Inhalt lebt unter [bjoernkawecki.de](https://bjoernkawecki.de/).

Diese Site (`blog.filingo.app`) liefert nur noch **Weiterleitungen** (HTML meta refresh + JS) auf die entsprechenden URLs:

| Filingo | Ziel |
| --- | --- |
| `/` | `https://bjoernkawecki.de/` |
| `/en/` | `https://bjoernkawecki.de/en/` |
| `/<slug>.html` | `https://bjoernkawecki.de/blog/<slug>.html` |
| `/en/<slug>.html` | `https://bjoernkawecki.de/en/blog/<slug>.html` |
| `/category/<name>/` | `https://bjoernkawecki.de/blog/category/<name>/` |

Nach dem Deploy prüfen, danach DNS/Hosting von `blog.filingo.app` optional auf Dauer umstellen oder abschalten.
